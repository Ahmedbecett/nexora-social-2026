## 🏗️ البنية التقنية

| الطبقة | التقنية |
|---|---|
| واجهة التطبيق | React 18 + Vite (ملف `src/`) |
| تطبيق أندرويد | Capacitor 7 (`android/`) — APK موقّع |
| الخادم (API) | Vercel Serverless Function واحدة: `api/index.js` → `api/_lib/handlers.js` |
| قاعدة البيانات | Neon PostgreSQL — المخطط في `api/_lib/schema.sql` |
| تخزين الوسائط | Vercel Blob (رفع مباشر من الجهاز عبر رموز مؤقتة) |
| المصادقة | Firebase Authentication (بريد · Google · هاتف) + جلسات JWT |

### متغيرات البيئة على Vercel
`DATABASE_URL` · `JWT_SECRET` · `BLOB_READ_WRITE_TOKEN` (مضبوطة بالفعل على مشروع `nexora-social-2026`).

### رمز الهاتف (OTP) مجاناً عبر هاتفك
بدلاً من رسائل Firebase المدفوعة، يرسل الخادم رمز التحقق عبر شريحة هاتف أندرويد خاص بك باستخدام تطبيق
[SMS Gateway for Android](https://sms-gate.app) (مفتوح المصدر ومجاني):
1. ثبّت التطبيق على هاتف أندرويد فيه شريحة (Djezzy / Mobilis / Ooredoo)، وفعّل **Cloud server** ثم **Online**.
2. انسخ **Username** و**Password** الظاهرين وضعهما في Vercel: `SMSGATE_USER` و`SMSGATE_PASS` (بديل: `TEXTBEE_API_KEY` + `TEXTBEE_DEVICE_ID`).
3. أعد النشر. عندها يستخدم التطبيق `POST /api/auth/phone/send` و`/verify` تلقائياً (رمز من 6 أرقام صالح 10 دقائق، 5 محاولات، حدود لكل رقم ولكل IP). إن لم تُضبط هذه المتغيرات يعود التطبيق إلى Firebase.

### الترجمات
ملفات اللغات في `src/locales/<code>.json`. لإعادة توليدها بعد إضافة نصوص جديدة:
```bash
node scripts/dump-en.mjs > /tmp/en.json && python3 scripts/translate.py
```

### التشغيل محلياً
```bash
npm install
DATABASE_URL=... JWT_SECRET=... BLOB_READ_WRITE_TOKEN=... npm run api:local   # API على :3001
npm run dev                                                                    # الواجهة على :5173
npm run db:migrate                                                             # إنشاء الجداول
```

### بناء APK
```bash
npm run build && npx cap sync android
cd android && ./gradlew assembleRelease
```
يبني GitHub Actions (`.github/workflows/android-release.yml`) ملف APK تلقائياً عند كل push إلى `main` وينشره في الإصدار `latest`.
لتوقيع البناء الآلي بنفس مفتاح الإصدار أضف الأسرار `NEXORA_KEYSTORE_BASE64` و `NEXORA_KEYSTORE_PASSWORD` في إعدادات المستودع.
