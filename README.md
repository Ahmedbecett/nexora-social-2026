## المزايا

- **محادثة ذكية حقيقية:** واجهة سريعة، Markdown كامل (عناوين، جداول، قوائم، معادلات LaTeX، أكواد مع نسخ)، بث تدريجي (SSE)، إيقاف التوليد وإعادة التوليد، تبديل النموذج وأسلوب الرد، دعم العربية (RTL) والفرنسية والإنجليزية.
- **محادثات متعددة:** إنشاء وتسمية وحذف وبحث، حفظ السياق في قاعدة البيانات، عزل كامل بين المستخدمين.
- **بحث ويب حقيقي:** نتائج فعلية من محركات حقيقية مع روابط المصادر تحت الإجابة، وتمييز ما هو معلومة موثّقة عمّا هو استنتاج.
- **ملفات وصور:** رفع PDF / DOCX / TXT وتحليلها، وتحليل الصور بنموذج رؤية فعلي، تخزين آمن بلا كشف روابط خاصة.
- **صوت:** قراءة الردود (TTS) وتحويل الكلام إلى نص (STT) عند توفّر الخدمة، مع إدارة إذن الميكروفون ورفضه بوضوح.
- **مساعدة برمجية:** كتابة وشرح وإصلاح وتحسين الكود بلغات متعددة مع تلوين ونسخ.
- **وضعان للمظهر** (فاتح/داكن) وواجهة متجاوبة للجوال وسطح المكتب.

## التقنية

- **الواجهة:** React 18 + Vite · `marked` + `DOMPurify` + `highlight.js` + `katex`
- **الخادم:** Vercel Serverless Functions (`/api`) — 133 مسارًا موثقًا تلقائيًا عبر `GET /api`
- **قاعدة البيانات:** PostgreSQL (Neon) — جداول المستخدمين والمحادثات `ai_*` والاشتراكات (`subscription_plans` · `user_subscriptions` · `payment_transactions` · `payment_webhook_events` · `usage_limits` · `usage_records` · `refund_records`)
- **التخزين:** Vercel Blob (ملفات وصور وصوت)
- **مزوّدو الذكاء الاصطناعي:** Gemini (محادثة/رؤية/صوت) + OpenRouter/OpenAI حسب التوفر + مزوّدو مفاتيح مجانية اختياريون (Groq · Cerebras · Mistral · GitHub Models) للاستمرارية بلا تكلفة
