## Long description — English

> **NEXORA AI — the AI workspace on Windows**
>
> NEXORA AI is the official Windows app for the NEXORA AI platform. It uses the same account, database
> and production cloud services as the web and Android editions. There is no separate account and no
> demo data.
>
> **What you can do**
> - Chat in Arabic or English with saved context and conversation history in your account.
> - Write, edit, summarise and translate, then review the result before using it.
> - Get coding help: examples, error explanations and improvements to existing snippets.
> - Analyse PDF, DOCX, text and images, and dictate a request with voice input.
> - Use web search with source links when the provider supports it.
> - **NEXORA Studio**: describe an app in plain language, get real files, edit them in a code editor,
>   run commands in a terminal, preview the result, then publish to GitHub or Vercel from the same account.
>
> **Made for Windows**
> - A standalone window with an integrated title bar and native window controls.
> - An app menu and shortcuts: `Ctrl+N` new conversation, `Ctrl+,` settings, `F1` shortcut list.
> - Light and dark themes plus clear loading and error states.
> - Install from the Microsoft Store, or as a Progressive Web App from Edge/Chrome.
>
> **Your account and security**
> - The same sign-in you already use on the web and Android.
> - HTTPS only, with no secret keys in the front end.
> - End sessions on all devices and delete your account from inside the app.
>
> **AI can make mistakes.** Verify important information before relying on it, especially for medical,
> legal or financial decisions. Read the privacy policy to understand how requests are processed.
>
