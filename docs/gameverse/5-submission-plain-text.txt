F. WHAT GAMEVERSE IS
--------------------
GameVerse is an independent international gaming platform combining instant browser games that run without installation, download listings that point to the official release pages of open-source and commercial titles, and a community layer of accounts, scores, reviews, leaderboards and daily challenges. The Android application is a native shell around the same live platform.

G. FEATURE INVENTORY
--------------------
Catalogue: 45 published games, 17 of them GameVerse originals built in-house
Instant play: HTML5 games in a sandboxed player
Downloads: verified pointers to official release pages
Accounts: e-mail sign-in with verification code
Community: reviews, favourites, play history, public profiles
Competition: leaderboards, daily challenges, achievements
Store: memberships and digital goods, server-verified pricing
Developer portal: studio registration, submission and review workflow
Languages: Arabic, French, English
Platforms: Android phones and tablets, Amazon Fire OS tablets, Fire TV

H. TECHNOLOGY
-------------
Next.js (React) server-rendered, TypeScript. Managed PostgreSQL encrypted at rest. Hosted on Vercel with serverless functions and edge delivery. Transactional e-mail provider for verification codes. Automated bot challenge on registration and login. Weekly digest job. Google AdSense on the web with Consent Mode v2, Google AdMob in the app (publisher pub-6858364141205978).

R. ACCOUNTS AND AUTHENTICATION
------------------------------
Accounts exist to keep scores, reviews and downloads genuine: one person, one profile. Sign-in uses an e-mail verification code; sessions are hashed server-side and secrets never reach the browser. Login and registration are protected by an automated challenge. Users can review and revoke active sessions.

S. CONTENT MODERATION AND REPORTING
-----------------------------------
Every game page carries a report action reaching studio moderation, and the help centre exposes a contact form at https://gameverse-henna.vercel.app/support. The developer portal enforces a written rights declaration from every submitter, automated security scanning of every upload, and admin review before publication.

T. SECURITY MEASURES
--------------------
Games run in a sandboxed player served from an isolated origin that cannot reach player sessions. Non-first-party advertising tags load only inside a dedicated frame with an opaque origin and no top navigation, so such a tag cannot read a session or redirect the tab. Uploads are scanned before publication and rejected if they attempt to touch platform credentials.
