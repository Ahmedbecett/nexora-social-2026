# Monetag OnClick web rollout — 2026-11-15

The owner supplied `https://quge5.com/88/tag.min.js` with zone `310646` and explicitly chose the OnClick/Popunder format on all website pages, including sign-in and signed-in AI screens. This is **not a persistent banner**: the network may open a new tab or window after a click. The tag's authenticity, account approval, fill and revenue are not verifiable from this repository. Adsterra has not been added because no approved Adsterra tag/zone was supplied.

## Implementation

- Every canonical HTML page (`/`, `/en.html`, About, Features, Download, FAQ and both privacy policies) includes the same deferred first-party `/monetag-web.js` bootstrap. The React homepage uses it on sign-in, registration, chat and other signed-in states because those states share the same document.
- On the canonical HTTPS production host, the bootstrap injects **one** asynchronous copy of the owner-supplied external tag with `data-zone="310646"` and `data-cfasync="false"`. It does not run on localhost, Vercel previews, native Android WebViews or browsers signaling Global Privacy Control. The bootstrap is served with revalidation so it can be changed quickly in a future deployment. Existing AdSense and native AdMob integrations are untouched.
- The bilingual privacy pages now disclose the new network, OnClick behavior and the fact that third-party scripts in web pages can technically access page content and inputs. The earlier SEO audit's "no JavaScript on static pages" measurement predates this requested advertising change; those pages now load the deferred ad bootstrap and, when eligible, the remote tag.

## Risks and owner follow-up

The external tag is heavily obfuscated and uses click handlers and browser storage. A script loaded in a top-level page executes with that page's privileges, including potential access to DOM inputs and locally stored login tokens. As requested, this risk applies even on sign-in and private chat pages. HTTPS, `async` and `referrerPolicy` do **not** sandbox the script. Monetag's own [OnClick description](https://help.monetag.com/en/articles/6726321-onclick-popunder-ads) calls the format a popunder triggered by user clicks. The owner should verify that this exact URL/zone came from the approved Monetag dashboard and that serving it alongside AdSense and on sign-in/chat pages follows both networks' policies. Global Privacy Control is honored, but it is **not** a complete consent management platform; obtain privacy/legal review and a suitable CMP where required before relying on this for regulated audiences.

Automated tests check all 12 HTML sources and production output, native/preview/GPC blocking, one-time insertion and the exact tag attributes. Local Vite preview will intentionally **not** request the external ad script. After production deployment, manually test sign-in, registration, a real chat, mobile layout, page navigation, network failures and browser popup blocking with a real authorized account; verify the zone in the Monetag dashboard. The repository cannot establish impressions or payment. If authentication or usability is affected, pause the zone in the provider dashboard immediately and remove `/monetag-web.js` from HTML in a follow-up deployment. Do not generate synthetic clicks or traffic.
