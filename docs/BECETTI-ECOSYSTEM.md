# منظومة BECETTI الرقمية الرسمية

## معاينة آمنة

- **الصفحة الرئيسية المؤقتة:** `/becetti/` (أو `/becetti/index.html`) على الاستضافة المجانية الحالية.
- **النطاق المستخدم الآن:** `nexora-social-2026.vercel.app`، وهو نطاق NEXORA الموجود مسبقاً. لم يُشترَ نطاق جديد ولم تُعدّل إعدادات DNS أو SSL.
- **مهم:** الصفحة الرئيسية `/` ما زالت تطبيق NEXORA AI الحالي. وُضعت منظومة BECETTI على مسار مستقل حتى لا يتغير رابط التطبيق المنشور أو إعداد PWA / Android / Windows قبل موافقة المالك.
- صفحات AR / EN / FR ثابتة ومهيأة للفهرسة. تختار الصفحات العربية العامة اللغة من تفضيلات المتصفح (Arabic / English / French) وتحافظ على المسار المناظر؛ اللغات الأخرى تبقى على العربية كخيار افتراضي ثابت. يحترم الموقع اختيار اللغة اليدوي لبقية جلسة التصفح. يمكن فتح اللوحة من `/becetti/admin.html`؛ صفحة الإدارة نفسها `noindex`.

## المنتجات والبيانات — دون مشاريع وهمية

الكتالوج الافتراضي يحتوي **منتجاً واحداً موثقاً** فقط: NEXORA AI، مع رابط الويب الحالي ورابط Android APK الموجود في المشروع. يظهر المنتج ضمن قسم Android وقسم Windows المنفصلين، ويحتوي كل عرض على رابط الموقع الرسمي. رابط Windows يفتح صفحة تعليمات التطبيق الفعلية `/windows/index.html` (تثبيت PWA)؛ لم يُضف رابط Microsoft Store أو Google Play، لأن صفحة المتجر الرسمية ليست منشورة. تحقّق ملفات Windows أن النشر في Microsoft Store ما زال قيد الاعتماد.

لا يُقبل حفظ أي مشروع من دون رابط موقع إلكتروني رسمي، ولا يُقبل تعيين Android أو Windows دون الرابط الرسمي المقابل. تظهر أقسام BECETTI AI / GAME / BUSINESS / SECURITY / TOOLS كلها، لكن الأقسام التي لا تملك منتجاً عاماً موثقاً تعرض رسالة صريحة بدلاً من اختراع تطبيق أو صورة أو رابط.

مصدر الكتالوج الافتراضي: `shared/becetti-catalog.js`. التحقق والتطبيع على الخادم: `api/_lib/becetti-catalog.js`.

## لوحة الإدارة والأمان

- API عام للقراءة: `GET /api/becetti/catalog`. يستخدم المتصفح `VITE_API_BASE` نفسه الذي يستخدمه تطبيق NEXORA؛ ويكون فارغاً على Vercel (نفس المضيف) ومضبوطاً في `.env.production` لبناء Firebase إلى واجهة Vercel الحالية.
- التعديل يتطلب مصادقة موجودة وصلاحية المالك في الخادم (`adminGuard`): `GET /api/becetti/admin` و`PUT /api/becetti/catalog`.
- لوحة الإدارة تستخدم جلسة NEXORA الحالية من المتصفح، ولا تحتوي كلمة مرور ثابتة أو مفتاح API. المستخدم الذي لا يملك صلاحية المالك لا يستطيع الحفظ حتى لو عرف رابط اللوحة.
- تُخزن نسخة الكتالوج في جدول `settings` الموجود في قاعدة بيانات التطبيق (`becetti_catalog`). يدعم الحفظ الأقسام والمنتجات والأوصاف بثلاث لغات والحالة والمنصات وروابط الموقع والتطبيق.
- رفع الشعارات اختياري. يصدر الخادم رمز رفع قصير العمر ومحدود النوع/الحجم عبر `POST /api/becetti/image-token`; مفتاح Vercel Blob يبقى على الخادم ولا يُرسل للواجهة.
- تحتاج وظائف الكتابة إلى متغيرات بيئة الخدمة الحالية (`DATABASE_URL` / `JWT_SECRET`)، كما يحتاج رفع الصور إلى `BLOB_READ_WRITE_TOKEN`.
- **المعاينة المحلية الحالية للوحة للقراءة فقط:** لا تحفظ ولا ترفع، لتجنّب تعديل بيانات النشر من رابط معاينة. قبل اختبار حفظ في Vercel Preview، تأكد أن Preview يستخدم قاعدة بيانات وتخزيناً منفصلين عن Production. لا تستخدم Production للتجربة.
- حذف قسم يحتوي منتجات ممنوع من الواجهة حتى تُنقل تلك المنتجات أولاً. روابط المتاجر اختيارية، وتظل فارغة ما لم يقدم المالك رابطاً رسمياً موثقاً.

## SEO وGoogle Search Console

- الملفات الثابتة ذات العناوين والوصف وcanonical وhreflang وبيانات Schema.org: `becetti/`.
- خريطة مستقلة لـ 33 صفحة BECETTI (11 صفحة × 3 لغات): `/becetti-sitemap.xml`، ويُعلن عنها مع خريطة NEXORA الحالية في `robots.txt` و`robots-webapp.txt`.
- لا يعاد استخدام رمز تحقق Google Search Console الخاص بـ NEXORA؛ فهو يثبت ملكية خاصية NEXORA الحالية فقط. أضف BECETTI إلى Search Console بعد اعتماد نطاق/خاصية BECETTI والتحقق منها بموافقة المالك. لم تُرسل أي بيانات دخول أو تغييرات خارجية.
- عند اعتماد نطاق لاحقاً، عيّن `BECETTI_SITE_URL` إلى العنوان الأساسي الكامل، ثم شغّل `npm run generate:becetti` وأعد النشر. حدّث كذلك robots وsitemap إلى المضيف المعتمد.

## البناء والتطوير

```bash
npm run generate:becetti
npm run dev
npm run build
npm test
```

`npm run build` يولد ملفات AR / EN / FR قبل Vite، ثم يضم صفحات `becetti/*.html` إلى ناتج `dist`. عند إضافة صفحة جديدة، حدّث مولّد الصفحات `scripts/generate-becetti-site.mjs` وخريطة المسارات في `vite.config.js` تُكتشف تلقائياً من ملفات HTML.

## نطاق النطاق والاستضافة

لم يتم شراء `.COM` أو تفعيل خدمة مدفوعة أو تغيير DNS. بعد اعتماد المعاينة، يُبحث عن مسجل يعرض **سعر السنة الأولى وسعر التجديد منفصلين**، ثم يُطلب تأكيد المالك قبل أي شراء أو ربط نطاق. SSL وDNS يظلان بلا تغيير حتى تلك الموافقة.
