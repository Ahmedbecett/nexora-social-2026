Install NEXORA AI on Windows

Two official paths, both connecting to the same secure backend at nexora-social-2026.vercel.app.

1 · PWA from the browser (available now)

Open the site in Microsoft Edge or Google Chrome on Windows, then choose Install from the address bar or the browser menu. The app appears in Start and runs in its own window.

2 · Microsoft Store (in certification)

The MSIX package is built from this repository and signed with the publisher certificate. Once the product is accepted, the install link appears here and on the Store listing.

Store product name: NEXORA AI by BECETTI.

  1. Open nexora-social-2026.vercel.app in Edge on Windows 10 (2004 or newer) or Windows 11.
  2. Wait for the app to load, then use the Install icon in the address bar (or ⋯ → Apps → Install this site as an app).
  3. Sign in with your existing account — no new account is created. Your conversations and projects are already there.
  4. Updates are handled by the service worker, which tells you when a new version is ready. Apply it from the bottom bar.
Honest note: no signed MSIX download is stored in this repository. Producing one requires a signing certificate from the publisher’s Partner Center account; the code, manifest and scripts are ready in windows/ and docs/windows/MSIX.md.

What you get on Windows

Not a demo and not a static wrapper: every request goes through the same production API.

Persistent AI conversations

Start a chat, keep the thread, and return to your history from the same account on any device.

NEXORA Studio

Describe an app, edit real files, run the terminal, preview the result, then publish to GitHub or Vercel.

Native Windows window

Window Controls Overlay title bar, an app menu, and Ctrl+N, Ctrl+, and F1 shortcuts.

Light and dark themes

Follows your saved preference or the system setting, with real loading and error states instead of a blank screen.

Offline shell

The cached interface opens when the network drops and clearly explains that new AI requests need a connection.

Keyboard and mouse

Visible focus, arrow-key menus and a safe reload when an update is ready.

Privacy and advertising

A separate policy written for the Windows edition explains what is stored locally and what is never done.

Data and account

Your conversations and projects belong to your account and are not shown to other users. Requests go to the secure backend only to produce the answer. Details

Advertising

No third-party ads are currently enabled inside the Windows app. A space is reserved in the layout, and any future provider requires explicit consent and written verification for the package type. Advertising policy

Security

HTTPS only, no secrets in the front end, and sessions can be revoked from Account & Security. Details
