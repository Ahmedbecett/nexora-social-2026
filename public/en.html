What can you do here?

Start with a question and follow up in the same conversation. Pick a focused tool for a first draft or a technical problem; your own judgement still matters when checking the answer.

AI chat and research

Explore a topic in Arabic or English, request a concise explanation and ask follow-up questions. Web search with source links is available when supported by the service.

Write, translate and summarize

Draft a message or outline, rephrase an awkward sentence, translate between languages or extract key points from a longer passage.

Code and create images

Ask for a code example or explanation, or describe an image you want to generate. Some features depend on provider availability and usage limits.
