About the project

A practical space for questions and creative work

NEXORA AI is developed by Ahmed Becetti (AI BECETTI). The current release centers on an AI workspace for everyday writing, learning and building tasks.

Why it exists

Moving between separate tools can interrupt an idea. NEXORA AI offers chat plus dedicated entry points for writing, coding, translation, summaries and images so you can move from a first question to a more useful draft in one place.

It is available through the website and a downloadable Android APK. An account is needed to send prompts and keep conversation history. The public information pages remain readable without one.

About the name

The project repository and web address include “social”, but this deployed version is NEXORA AI. It does not currently offer a public social feed, reels or direct messaging between users. Older social screens remain in the repository for reference but are not part of the running app. We do not advertise those unavailable features as live services.

Responsible use

Generated text and images can be useful starting points, not guarantees. Review outputs and verify important claims. Tools such as live search, voice and image generation may vary with device capabilities, usage limits and available providers.
